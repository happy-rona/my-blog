공부한 것과 일하면서 배운 것을 정리하려고 블로그를 만들었습니다.

Astro와 AstroPaper 테마로 만들고 GitHub Pages로 배포합니다.

> 인용문(`>`)은 Notion의 콜아웃처럼 회색 박스로 표시됩니다.

`인라인 코드`와 코드 블록도 Notion 스타일로 보입니다.

```ts
const hello = (name: string): string => `Hello, ${name}!`;
```
